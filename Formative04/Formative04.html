Learning Objectives

In this assignment, you will use Excel to define technical requirements, automate and test a business rule, and compare software acquisition options for SmartBean.

After completing this assignment, you will be able to:

  1. Estimate storage requirements and connect them to software deployment choices.
  2. Translate a business requirement into an automated Excel formula.
  3. Test normal and exceptional conditions using expected and actual results.
  4. Compare build, buy, and subscription software options using weighted criteria.
  5. Explain where automation is useful and where human judgment remains necessary.

Assignment Overview

SmartBean is considering software to support transaction records, security video, backups, AI-generated files, and operational calculations. Management must understand technical requirements, decide what should be automated, test the automation, and compare acquisition alternatives.

Exercise 2 — Automate and Test a Business Rule

SmartBean calculates Customer Orders per Labor Hour. The formula must handle four conditions:

  • normal positive inputs;
  • zero labor hours;
  • missing labor hours;
  • negative customer orders.
  1. Open 2-AutomationTesting.
  2. Review the nested IF() formula in the Orders per Labor Hour column.
  3. Confirm that normal rows return a numeric result.
  4. Confirm that exception rows return the intended message.
  5. Review Expected Result, Actual Result, and Pass/Fail.
  6. Decide which part should be automated and which part should remain under manager review.
